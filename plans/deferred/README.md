# Elhalasztott tervek

Ide kerülnek azok a korábban dokumentált tervek, amelyeket tudatosan
parkolópályára tettünk. Az áthelyezett tervben meg kell maradnia az elhalasztás
dátumának, indokának és annak, hogy milyen feltétel mellett vizsgálható újra.

Az itt szereplő terv nem aktív release-vállalás.
